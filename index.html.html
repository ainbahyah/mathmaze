Panduan Pemasangan Google Apps Script (GAS)

Langkah 1: Sediakan Google Sheets

  1. Buka Google Sheets baharu. Namakan sebagai "Rekod Math Maze Adventure".
  2. Di Lembaran 1 (Sheet1), cipta baris tajuk (Header) berikut pada baris pertama:
    Nama | Tingkatan | Kelas | Markah | Tempoh Masa | Baki Nyawa | Status | Tarikh & Masa

Langkah 2: Tambah Kod Apps Script (`Code.gs`)

Klik Extensions > Apps Script pada Google Sheets anda, padam semua kod sedia ada dan tampal kod Apps Script di bawah:

// ==========================================
// CODE.GS - GOOGLE APPS SCRIPT BACKEND
// ==========================================

function doGet() {
  return HtmlService.createTemplateFromFile('Index')
    .evaluate()
    .setTitle('Math Maze Adventure')
    .addMetaTag('viewport', 'width=device-width, initial-scale=1.0');
}

// Menyimpan Rekod Murid Ke Google Sheets
function saveGameRecord(record) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    sheet.appendRow([
      record.name,
      record.form,
      record.className,
      record.score,
      record.timeTaken,
      record.livesLeft,
      record.status,
      new Date().toLocaleString('ms-MY')
    ]);
    return { status: "SUCCESS", message: "Rekod berjaya disimpan!" };
  } catch (error) {
    return { status: "ERROR", message: error.toString() };
  }
}

// Mengambil Semua Rekod Untuk Paparan Guru
function getGameRecords() {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    var data = sheet.getDataRange().getValues();
    data.shift(); // Buang header row
    return data;
  } catch(e) {
    return [];
  }
}

Langkah 3: Terbitkan sebagai Web App

  1. Klik butang Deploy > New Deployment.
  2. Pilih jenis deployment: Web App.
  3. Execute as: Me (Akaun Guru).
  4. Who has access: Anyone (Sesiapa sahaja).
  5. Klik Deploy dan salin pautan URL Web App yang dihasilkan untuk diberikan kepada murid.

Panduan Permainan

  • 1. Gunakan Papan Kekunci (Arrow Keys) atau Butang Sentuhan Screen untuk menggerakkan watak.
  • 2. Terdapat 5 Stesen Matematik yang wajib dilawati secara berurutan.
  • 3. Jawapan **Betul**: +10 Markah & terus mara ke stesen seterusnya.
  • 4. Jawapan **Salah**: -1 Nyawa & watak akan dianjakkan berundur ke stesen sebelumnya.
  • 5. Sampai ke Pintu Destinasi (🏁) sebelum pemasa 10 minit tamat untuk mendapat Bonus +20 Markah!
